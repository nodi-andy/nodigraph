nodigraph — privacy

nodigraph runs entirely in your browser. A diagram is stored in the page link (#d=…), in a file you download, or — only if you run your own copy of the server with persistence switched on — on that server of yours.

nodigraph.com collects no personal data, sets no tracking cookies and runs no analytics. Live-collaboration sessions are peer-to-peer (WebRTC); the signalling server only helps two browsers find each other and stores nothing. "Open from GitHub" and "Save to GitHub" talk directly from your browser to GitHub with a token you provide; that token stays in your browser.

Fonts are loaded from Google Fonts, which is subject to Google's privacy policy.
